# 🛒 E-commerce Inventory SQL Analysis

## 📌 Project Overview

This project focuses on analyzing e-commerce inventory data using PostgreSQL and SQL. It explores product pricing, discounts, stock availability, product categories, and inventory-related business insights.

The project demonstrates how SQL can be used to clean, explore, and analyze product-level data to support retail and e-commerce decision-making.

## 🛠️ Tools Used

* PostgreSQL
* SQL
* pgAdmin
* CSV Dataset

## 📊 Analysis Areas

* Database and table creation
* Data import and exploration
* Data cleaning and validation
* Product pricing analysis
* Discount analysis
* Stock availability analysis
* Category-level inventory analysis
* Price-per-gram calculations
* Estimated inventory value and revenue analysis

## 📁 Dataset

The dataset contains e-commerce product inventory information, including:

* Product name
* Category
* MRP
* Discount percentage
* Discounted selling price
* Available quantity
* Product weight
* Stock availability

## 🚀 How to Use

1. Clone this repository.
2. Create a PostgreSQL database.
3. Import the `zepto_v2.csv` dataset.
4. Open `Zepto_SQL_data_analysis.sql`.
5. Execute the queries in PostgreSQL or pgAdmin.
